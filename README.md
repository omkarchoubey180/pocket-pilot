# PocketPilot — Student Expense Manager

A mobile-first student expense manager built to follow the supplied PocketPilot Figma design. It uses HTML, Bootstrap 5, custom CSS, and vanilla JavaScript.

## Files

- `index.html` — app screens and Bootstrap layout.
- `styles.css` — colors, typography, responsive mobile app frame, and components.
- `app.js` — navigation, budget calculations, expense form, search, category filters, and local browser storage.

## Open the project

Open `index.html` in a modern browser. Bootstrap and Google Fonts load from CDNs, so an internet connection helps with styling and typography. The sample expenses and budgets are fictional. Changes you make are saved in that browser's local storage.

## Screens and interactions

- **Home:** monthly balance, progress, weekly snapshot, and recent expenses.
- **Activity:** search and filter the 18 sample expenses, open details, and remove an entry.
- **Budgets:** category limits and remaining amounts; open category-specific details or edit any limit.
- **Add expense:** record an expense with a category, date, and optional note.
- **Weekly insights:** weekly spending chart and recent entries.
